# @api-profiler/node

Internal package of [api-performance-profiler](https://github.com/Nahid625/api-performance-profiler):
the framework-agnostic `Profiler` (request timing, in-memory request recorder
with display masking, the load-run safety gate, the autocannon-backed load
runner and the loopback JSON channel the CLI and VS Code extension read).

You do not install this directly — use `@api-profiler/express` in your app.

AGPL-3.0-only.

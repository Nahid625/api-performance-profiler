## 2. Dev.to - [Technical, developer-to-developer, markdown]
**Title: I built a VS Code extension that shows live API latency right next to your code ⚡**

Hey devs! 👋

If you build backends with Node.js, you know the drill: write a route, switch to Postman, test it, check the logs, guess the performance. I wanted to eliminate that context-switching.

So, I built the **API Performance Profiler** (v1.0 is out today!). 

### What it does:
- **Inline Latency:** It renders a live badge (like `🟢 84ms`) right next to your route definitions (`app.get` or `@Get`) inside VS Code.
- **1-Click Load Testing:** A CodeLens lets you hit the route 1,000 times in the background with real data.
- **Zero bloat:** No cloud, no heavy APMs. It runs entirely in local memory.
